Etiquetas de autocierre by Pau

<br>

La etiqueta br divide una línea dentro de un párrafo.
Esta frase aparece en una segunda línea gracias a ella.

<hr>

La etiqueta hr separa dos bloques de contenido y se muestra como una línea horizontal.

Este texto está después de la línea horizontal.

<img>

La etiqueta img muestra una imagen local. El atributo alt describe su contenido para accesibilidad y, si la imagen no carga, informa al usuario.

<input>

La etiqueta input crea controles para introducir datos, como este campo con placeholder y esta casilla para aceptar condiciones.

<link>

La etiqueta link se usa en el head para vincular recursos externos, como hojas de estilo, iconos o fuentes. En esta página la usamos para cargar el archivo CSS que da formato a la web.

<meta>

Las etiquetas meta aportan información al navegador: charset define la codificación, viewport adapta la página a pantallas móviles y description resume el contenido para buscadores.

<col>

La etiqueta col configura una columna dentro de un colgroup. En este ejemplo la primera columna tiene un fondo resaltado con CSS.

EtiquetaFunción

<embed>

La etiqueta embed incrusta directamente un recurso externo o local, como este SVG del proyecto, sin requerir un contenedor adicional.

<param>

La etiqueta param se usaba dentro de object para configurar un recurso embebido. En HTML5 está obsoleta y la mayoría de navegadores la ignoran, pero sigue siendo útil para entender su funcionamiento histórico.

<source>

La etiqueta source indica la ruta del recurso que debe intentar reproducir un elemento multimedia. Este ejemplo usa un video local, por lo que también funciona cuando la web se publica en GitHub Pages.

<wbr>

La etiqueta wbr indica un posible punto de salto dentro de una palabra muy larga. Si la ventana es estrecha, el texto puede dividirse sin romper la palabra de forma artificial:

supercalifragilisticexpialidociousdemostracion
