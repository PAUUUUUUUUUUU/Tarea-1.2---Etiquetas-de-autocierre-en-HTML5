Etiquetas de autocierre by Pau

<meta>

Las etiquetas meta aportan información al navegador: charset define la codificación, viewport adapta la página a pantallas móviles y description resume el contenido para buscadores.

<br>

La etiqueta <br> divide una línea dentro de un párrafo.
Esta frase aparece en una segunda línea gracias a ella.

<hr>

La etiqueta <hr> separa dos bloques de contenido y se muestra como una línea horizontal.

Este texto está después de la línea horizontal.

<img>

La etiqueta <img> muestra una imagen local. El atributo alt describe su contenido.

<input>

La etiqueta <input> crea controles para introducir datos, como este campo con placeholder y esta casilla.
